## Hi, I'm Ruilin 👋

I'm an engineering student at the University of Michigan interested in **embedded systems, intelligent sensing, real-time control, and applied machine learning**. I enjoy building complete systems—from sensor and signal pipelines to algorithms, hardware interfaces, and polished demonstrations.

- 🔭 Building embedded and perception systems that interact with the physical world
- 🧠 Interested in sensor fusion, computer vision, signal processing, and feedback control
- 🛠️ Comfortable moving between hardware, modeling, firmware, and data-driven methods
- 🎯 Seeking opportunities in embedded software, controls, robotics, and intelligent systems
